NEON AI PWA

Файлы:
- index.html — интерфейс приложения
- manifest.webmanifest — настройки установки как приложения
- sw.js — кэширование интерфейса
- icon.svg — иконка
- README_RU.txt — эта инструкция

Загрузка на GitHub:
1. Загрузите ВСЕ файлы из архива в корень репозитория (не сам ZIP).
2. В GitHub откройте Settings -> Pages.
3. Выберите Deploy from a branch, branch main, folder /(root), затем Save.
4. Дождитесь публикации сайта.
5. Откройте адрес сайта по HTTPS в Chrome Android и выберите «Установить приложение» или «Добавить на главный экран».

Важно: это демонстрационный интерфейс. Настоящие ответы ИИ требуют отдельного безопасного backend-сервера. Не вставляйте API-ключ в index.html.
